# Functions Overview

Below is the current list of supported functions in the scripting language.

| Function | Category | Description |
| :--- | :--- | :--- |
| `$title[text]` | Embed | Sets the title of the embed. |
| `$description[text]` | Embed | Sets the main body description of the embed. |
| `$footer[text;icon url]` | Embed | Sets the footer text and optional footer icon. |
| `$thumbnail[image url]` | Embed | Sets the small thumbnail image on the top right. |
| `$image[image url]` | Embed | Sets the main large image inside the embed. |
| `$sendMessage[text]` | Messaging | Sends a message/embed response to the channel. |
