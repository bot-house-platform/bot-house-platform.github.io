# Welcome to BHScript!

Welcome to the official documentation for the Bot House! This language allows you to build powerful Discord bot responses using simple, readable function syntax.

## Features

- **Simple Syntax:** Functional syntax built around square brackets like `$function[arguments]`.
- **Rich Embed Support:** Easily format titles, descriptions, images, and footers for Discord messages.
- **Message Sending:** Control where and what messages are sent with minimal code.

## Quick Example

```bhscript
$title[Hello World!]
$description[This is my very first Discord script!]
$footer[Powered by Discord Scripting;https://example.com/icon.png]
$sendMessage[Check out this cool response!]
```
